# Responsive Header Fix

Récupères à l'identique le site https://reboot-dole-v3.lovable.app/, nous allons y apporter une modification : entre 702 pixels et 900 pixels de largeur, il y a un problème avec le header qui est le header desktop, hors il faudrait garder le menu burger car en dessous de 900pixels les boutons du header conflictent avec le logo "Reboot" à gauche faute de largeur suffisante.

Par ailleurs, en dessous de 702 pixels le label du bouton whatsapp est juste "whatsapp", pas certain que ce soit le meilleur label pour le bouton, fais moi quelques suggestions plus parlantes pour le end user qui ne changeraient pas la largeur du bouton.
